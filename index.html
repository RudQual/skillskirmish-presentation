SkillSkirmish

Intelligent Developer Matchmaking & Collaboration

"The primary objective of SkillSkirmish is to solve the problem of skill-based developer matchmaking by creating a system that dynamically assesses and tracks developer skills using AI-generated adaptive assessments and uses this data to enable intelligent collaborator discovery and real-time collaboration."

Problem Statement

Developers lack an intelligent platform that helps them discover suitable collaborators, evaluate their actual skill levels, and collaborate effectively in real time. Collaboration is often inefficient due to skill mismatch, unverified abilities, and fragmented tooling.

Collaboration Discovery Gap

No reliable way to identify collaborators with matching, verified skill levels. Developers don't know who to team up with.

Skill Verification Gap

Most platforms rely on self-claimed skills. No dynamic system to measure real ability through performance.

Platform Fragmentation

Discord/Zoom for calls, LeetCode for skills, LinkedIn for profiles — no single platform integrates assessment + matchmaking + collaboration.

Literature Review & Research Gap

Existing Platforms Analyzed

Discord / Zoom

Communication only — no skill measurement or matchmaking

Skill assessment only — no real-time collaboration support

Research Gap / Innovation

No existing platform combines all three pillars: verified skill assessment, intelligent matchmaking, and integrated collaboration into a single unified environment.

SkillSkirmish bridges this gap by using AI-generated adaptive questions and an ELO-based rating system that dynamically tracks developer skills and powers intelligent collaborator discovery.

Theory & Background

ELO Rating System

Adapted from chess. AI-generated question difficulty maps to ELO (Easy=1000, Medium=1200, Hard=1400). Rating adjusts via expected probability formula with variable K-factor.

Skill Decay Model

Skills decay at 2pts/week of inactivity. Ensures ratings reflect current ability. Users receive notifications encouraging re-assessment to maintain their ELO.

AI-Powered Assessment

Questions are generated by AI (Groq/Google Generative AI) in real-time. Mixed format: 8 coding, 6 MCQ, 6 subjective per session. Subjective answers also graded by AI.

Core Features

AI Adaptive Assessment

AI-generated quizzes per specialization. Mixed coding/MCQ/subjective. ELO-rated difficulty. No fixed question bank.

Smart Matchmaking

API Endpoints

Assessment API — AI-Powered

POST/api/assessment/start

Purpose: Start a new assessment session. Generates the first AI question.

Input: { skill } · Output: { question, options, type, difficulty, codeTemplate, testCases }

Internal: Builds question plan (8 coding, 6 MCQ, 6 subjective), calls AI model to generate first question, creates AssessmentSession in DB.

POST/api/assessment/submit

Purpose: Grade user answer and generate next AI question.

Input: { userAnswer } · Output: { scorePercentage, feedback, correctAnswer, nextQuestion }

Internal: MCQ: exact match. Subjective/Coding: AI evaluation via evaluateSubjectiveWithAI(). Logs result, generates next question from AI.

POST/api/assessment/finish

Purpose: Calculate final ELO from all answers and update user skill rating.

Input: None (uses session) · Output: { accuracy, oldRating, newRating, ratingChange }

Internal: Calculates ELO change using expected probability formula, updates User.skills in MongoDB.

POST/api/assessment/skip

Purpose: Skip current question, generate next AI question without grading.

Matchmaking

POST/api/matchmaking/find-match

Input: { requiredSkills, minElo }

Internal: Queries MongoDB for users with matching skills & ELO range, returns top 10 matches with scores.

Authentication

POST/api/auth/register— Create account, hash password (bcrypt)
POST/api/auth/login— Returns JWT token
GET/api/auth/user— Get authenticated user

Rooms

CRUD operations for collaboration rooms. Manages members, video calls (start/join/leave/delete), and room access requests. Socket.io handles real-time room state.

Projects & Files

Project CRUD within rooms. File management (create/read/update/delete) for collaborative IDE. Code execution via sandboxed runner.

Database Schemas

Stores user accounts, profile info, skills with ELO, assessment history, and social links.

Results & Analysis

Skill VerificationELO
Question SourceAI-Gen

SkillSkirmish outperforms existing platforms by using AI-generated adaptive questions and integrating verified skill assessment directly into matchmaking and collaboration.

Validation Strategy

  • Compare self-reported skill accuracy vs. AI-assessed ELO accuracy
  • Measure collaboration satisfaction pre/post matchmaking
  • Track ELO distribution stability across user base
  • A/B test: random matching vs. skill-based matching outcomes

Risk & Mitigation

  • Cold start: Provisional rating (K=40) until 30+ questions answered
  • AI failures: Built-in fallback questions if AI generation fails
  • Gaming: Duplicate avoidance + AI-graded subjective answers prevent exploitation
  • Inactivity: Weekly skill decay (2pts) ensures current ability reflection
